# ZUI_LEAVE_O4

## Service Binding

| Property | Value |
|---|---|
| Binding Name | ZUI_LEAVE_O4 |
| Binding Type | OData V4 - UI |
| Service Definition | ZUI_LEAVE |
| Status | Published |

## Exposed Entities

- LeaveRequest
- LeaveSummary

## Purpose

The service binding exposes the Employee Leave Management RAP business service through OData V4 for consumption by SAP Fiori Elements.

## Application

The service was tested using the SAP Fiori Elements Preview in ADT.

### LeaveRequest

- Create
- Read
- Update
- Delete
- Approve
- Reject

### LeaveSummary

- Read
